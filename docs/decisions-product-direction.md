# 决策记录：产品方向（Grill）

- **日期**：2026-10-25
- **强度**：拷打

## 已确定

- **D-G1 第一用户**：仅自己（店长），非对外客户/工作室
- **D-G2 核心痛点（口述）**：记单靠微信备注 + 手写，临时昵称后期对不上；回头客靠记忆，客户改名/头像易丢识别
- **D-G3 为何还没日用**：老订单需导入并规范化；单量少时不急；单量上来后 UI/各处显得乱
- **D-G4 游戏范围（当前 + 规划）**：伊莫、异环、鸣潮；后续无限大、白银之城等（多游戏仍是目标，但是否第一版全做待定）
- **D-G5 客户识别**：手机号 + 内部备注名为主；不依赖微信号/微信昵称（可改）
- **D-G6 老单来源**：Excel、微信聊天、闲鱼记录；Cheezit 另一版 UI，基本不管/不迁
- **D-G7 规范化含义**：统一「下单内容」口径（聊天说法、Excel 不同命名、同内容异名要对齐）
- **D-G8 第一版游戏范围**：只跑通异环；其他游戏流程类似，后置
- **D-G9 异环订单字段（用户口述）**：客户、联系方式、下单渠道、游戏、具体内容、服务器、打手、金额、实际到手、是否打完、下单时间、完成时间；备注可选
- **D-G10 导入策略**：C — 先 Excel 批量；微信/闲鱼仅核对补漏
- **D-G11 两周成功标准**：用户要 A+C（Excel 老单全进且口径统一 + UI 再打磨）；与「功能已齐、主要是信息架构」的自我诊断并存，待下一轮拆开优先级
