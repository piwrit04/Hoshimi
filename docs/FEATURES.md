## 订单（`/orders`）

**列序（全列居中，双行密度）：**

| 列 | 内容 |
|---|---|
| 勾选 | 批量完成 |
| 订单号 | 可点开编辑 |
| 客户 + 联系 | 上昵称（可跳客户）· 下联系方式 |
| 订单内容 | 上游戏/「托管」· 下项目；托管到期并入次行（最多两行） |
| 下单平台 | 上平台 · 下转单标记 |
| 金额 · 到手 | 上金额 · 下到手（品牌粉 #EE7093 强调）；作废单到手作废 |
| 下单 · 完单 | 日期带时分 |
| 状态 | 胶囊同皮（浅深一致） |
| 操作 | 编辑 / 更多（退款·取消） |

**筛栏 / 页头：**
- 筛栏单行：分段左，筛选+搜索右（搜索在最后）；≤1024 才换行
- 分段激活：浅粉底 + 粉字 `#D8A0BC` + 细粉边；未激活 `foreground/0.6`
- 页头左右：标题+汇总 | 新建订单（页头导出已撤）

**录单抽屉：**
- 分区卡片、金额条、明细小行卡、目录快加
- 校验：客户必填、普通单每行分类+项目、托管类型/结算/起止日/金额、转单比例或金额
- 托管类型：聚合该游戏**全部托管分类**的项目；目录为空时可手填类型
- 周结自动算结束日（+7）并有说明；转单默认打手 80% 有提示；保存 toast「已记下」
- `openWithCustomer`：从客户「记一单」预填昵称/联系

**深链：** `?mode=&period=&anchor=completed` — 概览「今日到手」用 `mode=已完成&period=today&anchor=completed`（按 **完成日**，非下单日）。`cc0fd44`：深链**覆盖**筛记忆；侧栏进订单清默认筛。文案口径：待处理 / 待收口 / 已完成消费。

## 客户（`/customers`）

- 显式建档 + 记单自动建档
- 合并：详情 `?merge=`；有订单不可删（先合并）
- 订单链客；已合并 id 跳保留客户
- 记一单预填（`openWithCustomer`）
- 列表「消费 · 已完成」= 已完成合计（未完成不计）
- **导出当前列表 CSV**（筛选后导出）
- 详情：头像 `ds-rise`、KPI `ds-stat`、订单表同皮

---

## 待办（`/todo`）

- 真实账本：催单（普通）+ **进行中**托管到期（与概览同口径；待处理未开工不进到期）
- 完成 / 取消；侧栏角标
- **自由待办（密度对齐 `0d93fba`）**：角标=未完成数；有已完成行时副文案「含已完成」。本机 `localStorage`（`free-todos-storage`），不进 IndexedDB

## 目录 / 设置（`/settings`）

- 项目目录 CRUD + **上下键排序**落盘（拖拽后置）
- 分类编辑可改 **kind（普通 ↔ 托管）**（左侧普通/托管角标 + 右侧「编辑」）；只影响之后录单，旧单文字保留
- 清理缓存、主题、导入导出、重开引导（不清账本）

## 概览（`/dashboard`）

- 累计：服务天数、已成交、累计到手、服务用户
